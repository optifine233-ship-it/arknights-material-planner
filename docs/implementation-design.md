# 新版实现设计

## 单一目标

帮助《明日方舟》玩家把“我有哪些干员、目前练到哪里、准备练到哪里”转换为可核对、可追溯的材料清单。

## 数据边界

- 游戏数据：干员、养成项目、材料、配方、图标与头像。由版本化静态数据提供。
- 用户数据：拥有状态、当前状态、目标状态、库存和界面设置。只保存在浏览器本地，可导入导出。
- 外部格式：由独立适配器转换到内部用户数据，不能渗透到计算和界面代码。

## 内部状态

每名干员保存 `owned`、`current` 和 `target`。当前与目标都使用精英阶段、等级、技能等级、各技能专精和各模组阶段表达，目标不能低于当前状态。

旧页面的 `ak_plan`、`ak_levels` 和 `ak_inv` 会在首次启动时只读迁移；迁移完成后保留原键作为回退依据，不主动删除。

## 计算管线

1. 比较每名干员的当前状态和目标状态，生成逐项升级记录。
2. 每条记录保留干员、强化项、直接材料、经验和龙门币。
3. 逐条材料递归分解到对应类别的展示基准层。
4. 统一分配共享库存，先抵扣同名成品，再使用低阶库存进行整数合成。
5. 同一份计算结果供干员明细、材料汇总、缺口和统计页使用。

任何汇总数字都必须能够下钻回逐项升级记录。

## 界面方向

- 主题：罗德岛后勤作战板。
- 色彩：雾灰 `#E9ECEB`、纸白 `#F7F8F6`、墨黑 `#141A20`、结构灰 `#66717D`、信号黄 `#E7B53A`、战术蓝 `#2A91B7`、缺口红 `#C84D4D`。
- 字体：标题与关键数字使用 Bahnschrift Condensed/Arial Narrow，正文使用 Microsoft YaHei UI/Noto Sans SC，数据标签使用 Cascadia Mono。
- 布局：桌面端左侧分类索引轨，右侧为当前任务工作区；移动端改为底部导航和抽屉详情。
- 标志性元素：索引轨使用真实的 `OPS`、`PLAN`、`STOCK`、`GAP`、`STATS` 分类代码，不使用无意义装饰编号。

## 交付策略

- 旧版 `arknights_tool.html` 保留为回归参照，直到新版通过完整验证。
- 新入口为 `index.html`，使用浏览器原生 ES 模块，无需构建即可部署到 GitHub Pages。
- 核心计算和格式适配使用 Node 内置测试，界面再通过本地浏览器完成桌面与移动端验证。
