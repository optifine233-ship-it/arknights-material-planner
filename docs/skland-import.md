# 从森空岛导入养成进度

本站不会要求你粘贴森空岛 token、Cookie、手机号、密码或验证码。森空岛导入由一个本地用户脚本完成：脚本只在 `www.skland.com` 运行，从森空岛读取养成数据后下载一份脱敏 JSON，再由你手动导入本站。

## 使用方法

1. 在浏览器安装 Tampermonkey 或 Violentmonkey。
2. 从本站“导入 → 从森空岛导入”安装 `skland-cultivation-export.user.js`。
3. 登录 [森空岛](https://www.skland.com/)；页面右下角会出现“导出养成快照”。
4. 点击按钮。若账号绑定了多个明日方舟角色，按提示选择一个角色。
5. 浏览器会下载 `skland-cultivation-日期.json`。回到本站选择该文件，查看预览后确认合并。

快照包含干员拥有状态、精英阶段、等级、潜能、技能等级、专精和模组状态；不包含 UID、昵称、账号凭据，也暂不包含库存。现有培养目标不会因导入而降低。

森空岛接口不是公开承诺的第三方接口，因此首版只提供安全合并：快照中没有出现的干员不会被改成“未拥有”；字段不完整时会停止导出或导入，不使用零值覆盖本机记录。

## 安全边界

- 用户脚本只匹配 `https://www.skland.com/*`，只连接 `https://zonai.skland.com`。
- 凭据只在用户主动点击导出时从森空岛网页读取，使用结束后立即从脚本内存中丢弃。
- 凭据不会写入本站、本地备份、用户脚本存储、剪贴板或网址。
- 脚本不使用公共 CORS 代理，不加载第三方远程代码，不读取浏览器 Cookie。
- 本工具非鹰角网络或森空岛官方。接口发生变化时，导出可能暂时失效，但不会改用权限更大的接口兜底。

如果导出失败，请先刷新森空岛并确认仍处于登录状态；仍无法解决时，可以改用本站备份或 MAA 导入。反馈问题时不要附带 token、Cookie、完整 UID 或未经检查的日志。
