# 明日方舟干员养成材料统计

一个直接在浏览器中使用的《明日方舟》干员养成计划与材料缺口工具。它把每名干员的当前状态和目标状态拆成可核对的培养项，并统一统计库存抵扣后的材料缺口。

> 本项目为玩家制作的非官方工具，与上海鹰角网络科技有限公司、PRTS Wiki、MAA 均无隶属或授权关系。

## 已实现

- 从 PRTS MediaWiki API 生成完整、版本化的干员与材料快照。
- 按职业、分支职业、星级、部署位置、拥有状态和计划状态筛选干员。
- 记录当前与目标的精英阶段、等级、技能、专精和完整模组阶段。
- 逐项显示直接材料与分解到展示基准层的材料，并统计全局缺口。
- T2 普通材料库存可按整数配方抵扣 T3 缺口，多个需求共享同一份库存。
- 单独统计作战记录、龙门币、芯片、双芯片、芯片助剂与采购凭证等效值。
- 浏览器本地自动保存，并支持完整 JSON 导入、导出和替换前备份。
- 导入 MAA 干员识别 JSON 中的拥有状态、精英阶段、等级和潜能。
- 通过本地用户脚本从森空岛导入等级、技能专精和模组状态；本站不接触账号凭据。
- 桌面与移动端响应式界面，以及账号资源累计、培养缺口和积累时间估算。

## 使用

公开部署后直接访问 GitHub Pages 即可。个人数据默认只保存在当前网站域名下的浏览器中；更换设备、浏览器或网站地址前，请先点击“导出备份”。

首次进入时可以选择四种开始方式：

- **直接使用**：不导入个人数据，适合先体验功能；之后仍可随时补充进度。
- **从森空岛导入（推荐）**：导入拥有状态、等级、潜能、技能等级、专精和模组。本站不接触账号凭据，具体步骤见 [从森空岛导入养成进度](docs/skland-import.md)。
- **导入本站备份**：完整恢复此前导出的当前进度、培养目标、库存和页面设置。
- **导入 MAA 结果**：粘贴 MAA“干员识别”结果，导入拥有状态、精英阶段、等级和潜能。

MAA 当前不提供技能等级、专精和模组状态：首次导入的干员按技能 1、未专精、未解锁模组记录；本工具中已有的技能、专精、模组及所有目标状态会保留。森空岛导入会先在森空岛网页生成一份不含 UID、昵称和凭据的脱敏 JSON，再回到本站预览并安全合并；暂不导入库存，也不会把快照中未出现的干员标记为未拥有。请勿在本站粘贴森空岛 token、Cookie、手机号、密码或验证码。

## 本地开发

需要 Node.js 20 或更新版本。

```bash
npm run dev
npm test
npm run check
```

浏览器打开命令输出中的本地地址。`index.html` 是新版入口；两个 `arknights_*.html` 文件仅作为旧版存档，不再参与数据选择或生成。

## 更新数据

```bash
npm run sync:prts
npm run check
```

同步脚本通过 PRTS MediaWiki API 获取干员、材料、配方和图片地址，带有请求间隔、`maxlag` 与数量安全阈值。GitHub Actions 每周运行一次；只有数据版本变化时才产生新的发布时间。

用户打开页面时只请求很小的 `data/data-version.json` 检查版本；需要时再加载完整快照。验证成功的数据会写入 IndexedDB，网络不可用时回退到最近缓存。

## 项目结构

- `src/`：界面、计算、统计、存储、数据加载和外部格式适配器。
- `scripts/`：旧数据提取、PRTS 同步、本地服务器和数据校验。
- `data/`：发布时使用的版本化静态数据。
- `tests/`：材料计算、状态迁移、统计、PRTS 解析、MAA 与森空岛导入测试。
- `userscripts/`：只在森空岛网页运行的脱敏养成快照导出脚本。
- `arknights_tool.html`：旧版单文件页面，仅作对照存档。
